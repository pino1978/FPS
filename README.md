# Football Prediction System

Repository pubblico del Football Prediction System (FPS): prodotto mobile-first che trasforma dati calcistici versionati in probabilità, indicatori di qualità, analisi Value e sistemi verificabili.

## Principi

- Probability, Confidence, Data Quality, Value e Pick Score sono metriche distinte.
- NO_BET è un risultato valido.
- Prediction, paper trading e giocate reali sono separati.
- Snapshot, modelli, configurazioni e regole sono versionati.
- Nessun dato mancante viene inventato.

## Stato

La Phase 0 è completa documentalmente. Restano trial/licenze provider e usability test con utenti reali.

## Struttura

- docs/baseline: SRS, Technical Design e MVP Backlog vincolanti.
- docs/phase-0: decisioni, architettura, UX, gate e QA.
- prototype: prototipo UX navigabile.

Aprire prototype/index.html per esplorare il prototipo.

## Avvertenza

Il progetto non esegue scommesse e non promette vincite. Utilizzo riservato ai maggiorenni.
